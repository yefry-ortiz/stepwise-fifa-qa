# context-pack/

Shared runtime standards loaded by the capability harness alongside every skill.

## Files

| File | Purpose |
|------|---------|
| `system/execution-protocol.md` | Agent session identity, state management, context-limit handling, `_progress.json` spec, and recovery standards. Referenced by all skills that manage session lifecycle or output progress signals. Copied by Stepwise into `./context-pack/system/`. |
| `system/sap-abap-archaeology-standards.md` | SAP ABAP archaeology analysis standards defining source-export-first posture, read-only rules, ABAP object vocabulary, and Clean Core signal definitions. Used by `sap-abap-archaeology` capability. |
| `test-standards.md` | Quality engineering test standards defining test execution protocols, quality gates, test pyramid configuration, performance benchmarks, security testing, accessibility compliance, and reporting standards. Referenced by all testing-related capabilities. |
| `automation-standards.md` | Automation framework standards defining architecture patterns, Page Object Model implementation, code generation templates, configuration management, execution protocols, and quality gates for automation engineering. Used by automation pipeline capabilities. |
| `validation-tools.md` | Deterministic validation tool catalog used by skills with quality-gate steps. Generated by the user and placed in `./context-pack/` (not managed by Stepwise). |

## Standalone Skill Execution

When running a skill **inside a capability** (Stepwise, capability YAML, or orchestrator),
these files are loaded automatically — no action required.

When running a skill **standalone** (direct CLI invocation, ad-hoc agent session, or any
context without a capability harness), you must attach both files explicitly:

```bash
# CLI / agent session — attach to context before activating the skill
context-pack/system/execution-protocol.md
context-pack/test-standards.md
context-pack/automation-standards.md
context-pack/validation-tools.md
```

For Stepwise, include them in the capability YAML:

```yaml
context_files:
  - context-pack/system/execution-protocol.md
  - context-pack/test-standards.md
  - context-pack/automation-standards.md
  - context-pack/validation-tools.md
```

## Quality Engineering Standards

### Test Standards (`test-standards.md`)
Comprehensive testing framework standards including:
- Test execution protocols across all testing levels (Unit, Integration, E2E)
- Quality gate definitions with specific metrics and SLAs
- Test pyramid configuration (30% Unit, 40% Integration, 30% E2E)
- Performance testing benchmarks and load testing scenarios
- Security testing standards (SAST, DAST, dependency scanning)
- Accessibility compliance (WCAG 2.1 AA)
- Defect management lifecycle and classification
- Test coverage metrics and reporting standards

**Used by**: All testing-related capabilities including `defining-qe-strategy`, `globant-qe-test-plan`, `generating-e2e-test-cases`, and `automation-test-execution`.

### Automation Standards (`automation-standards.md`)
Complete automation framework engineering standards including:
- Automation framework architecture and design patterns
- Page Object Model (POM) implementation standards
- Code generation templates and conventions
- Configuration management and environment handling
- Test data management and fixture patterns
- Automation execution protocols and reporting
- Code review checklists and compliance validation
- Performance optimization strategies
- Security and compliance requirements

**Used by**: Automation pipeline capabilities including `framework-exploration`, `automation-planning`, `automation-code-generation`, and `automation-test-execution`.

### Capability-Specific Standards

#### SAP ABAP Archaeology (`system/sap-abap-archaeology-standards.md`)
Specialized standards for SAP ABAP analysis:
- Source-export-first access mode
- Read-only and no-secrets posture
- ABAP object vocabulary and classification
- Clean Core signal definitions
- Evidence-based analysis requirements

**Used by**: `sap-abap-archaeology` capability and related ABAP analysis skills.

## File Loading Priority

1. **Always Loaded**: `system/execution-protocol.md` (required for session management)
2. **Capability-Specific**: Load based on capability type:
   - Testing capabilities → `test-standards.md`
   - Automation capabilities → `automation-standards.md`
   - SAP capabilities → `system/sap-abap-archaeology-standards.md`
3. **Optional**: `validation-tools.md` (for skills with quality-gate steps)
